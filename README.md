# HallSpan 考场间距排座

在考室网格上按最小曼哈顿距离排座，同试卷套不得四邻相邻，并输出违规与统计。

## 场次封闭状态（与开放互斥）

- **封闭场**：提交排座时，只要该考室存在至少一名「关键考生」，场次即进入封闭。
  未排入口关闭，统计未排必须为 0（全员落座）；若格位紧张做不到全员落座，
  则整场失败、不新增方案，失败说明仅为「封闭场必须全员落座」。
- **开放场**：没有任何关键标记时场次为开放，才允许现网未排（部分考生未排上）。
- 封闭与开放互斥；在「考生名册」改动关键标记后，状态于**下一次提交排座的瞬间**切换，
  不沿用旧方案图（`/seating/latest` 用 `current_status`/`stale` 提示快照已过期）。
- 本规则不要求坐前排。

技术栈：Python 3.12 / FastAPI / SQLAlchemy / PostgreSQL / Vue 3 / TypeScript / Vite

## 启动

```bash
docker compose up --build
```

| 服务 | 地址 |
| --- | --- |
| 前端 | http://localhost:4900 |
| API | http://localhost:9900 |
| API 文档 | http://localhost:9900/docs |
| Postgres | localhost:5450 |

健康检查：`GET http://localhost:9900/api/health`

## 使用说明

1. 在「考室」「考生」「试卷套」确认基础数据；在「考生名册」用「标为关键」维护关键考生标记。
2. 打开「排座图」点「提交排座」执行间距排座；按关键标记自动进入封闭或开放。
3. 在「违规」查看间距或同卷相邻问题（封闭场不显示未排入口）。
4. 在「统计」查看场次状态、占用与违规汇总。
